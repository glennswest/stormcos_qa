## 1. Dependencies since 2026-10-06

- **russh** (lock: 0.63.3, russh-cryptovec 0.62.0). Debian's tracker lists CVEs
  with fixes in 0.60.1, 0.60.3, 0.62.4–0.62.6, 0.63.0, 0.63.1 and 0.63.2
  ([tracker](https://security-tracker.debian.org/tracker/source-package/rust-russh)).
  0.63.3 is at or past every stated fix. Several entries have truncated
  descriptions (CVE-2026-102820 pageant, CVE-2026-48107/48108/48110,
  CVE-2026-46702/46705 show no fixed version), so those are unverified.
  Debian sid ships 0.64.1, so a newer line exists. No item is actionable until
  the truncated ones are read in full.
- **SQLite** (rusqlite 0.37.0 / libsqlite3-sys 0.35.0, bundled). SQLite 3.53.2
  fixed FTS5 memory corruption
  ([CVE-2026-11822](https://security-tracker.debian.org/CVE-2026-11822),
  [CVE-2026-11824](https://security-tracker.debian.org/CVE-2026-11824)) and
  3.53.1 had Session Extension bugs
  ([MGASA-2026-0305](https://osv.dev/vulnerability/MGASA-2026-0305)). The
  sqlite workload (`/test sqlite`) uses neither FTS5 nor sessions and opens only
  its own database, so this is not exposed. Not verified: which SQLite version
  libsqlite3-sys 0.35.0 bundles.
- **rustls, reqwest, tokio, quinn, aws-lc-sys, ring**: no RUSTSEC/CVE hit in two
  searches. October 2026 RUSTSEC entries seen were wasmtime and unrelated crates
  ([RUSTSEC-2026-0327](https://www.wiz.io/vulnerability-database/cve/rustsec-2026-0327)).
  Search is not a substitute for `cargo audit`.
- Images pulled: none (scratch image, no base).
